## Definitions

**Severity:**
- **Critical:** Blocks core functionality, crash, data loss
- **Major:** Feature broken, significant UX impact
- **Minor:** Cosmetic, small friction
- **Enhancement:** Feature request, improvement

**Status:**
- `Open` - Not started
- `In Progress` - Being worked on
- `Fixed` - Resolved, pending deploy
- `Deployed` - Live
- `Won't Fix` - Decided not to address
